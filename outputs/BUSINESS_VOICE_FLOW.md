# 商务语音工作台：业务流程

## 核心闭环

1. 用户点击或上滑语音组件，开始录音。
2. 后端完成语音转写，再交给大模型识别意图。
3. 大模型只路由到四类业务：会议总结、语音备忘、工具调用、商务问答。
4. 前端展示结构化结果；所有外部工具操作必须二次确认。
5. 用户确认后保存产出或调用工具，并记录执行结果与审计日志。

## 会议总结

录音/上传会议 → 转写与说话人分离 → 提取议题、结论、决策、待办、负责人、截止时间、风险 → 用户校对 → 保存纪要 → 可选择创建任务或发送摘要。

## 语音备忘

口述内容 → 提取标题、摘要、标签、相关项目 → 用户确认 → 保存 → 可选设置提醒或关联客户/项目。

## 工具调用

用户说“给团队发摘要”“创建明天下午会议”“把待办同步到任务系统” → 大模型生成结构化参数 → 展示预览 → 用户确认 → 后端调用邮件、日历、CRM 或任务系统 → 返回成功/失败结果。

## 安全边界

- API Key 仅保存在后端环境变量。
- 发邮件、创建会议、删除数据等外部动作必须在执行前确认。
- 保存原始转写、模型结果与执行日志，支持追溯。
- 对人名、日期、金额、负责人等关键字段做缺失检查，不允许模型自行补全。

## 建议的数据对象

- Recording：音频、时长、创建人、转写状态。
- Transcript：全文、说话人、时间戳、置信度。
- BusinessArtifact：会议纪要或备忘的标题、摘要、正文、标签。
- ActionItem：任务、负责人、截止时间、状态。
- ToolRun：工具名称、参数预览、确认人、执行结果、审计时间。
